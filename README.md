# Group Internship

A 10-week internship group challenge project.

**Status:** repository setup. The project brief, team, technology stack, start
date, and assessment requirements will be confirmed before implementation.

## Getting started

```sh
git clone --recurse-submodules https://github.com/STERILITZIA02/Group-Internship.git
cd Group-Internship
```

There is no application or build command yet. Setup instructions will be added
once the team agrees on the project and technology stack.

## Working together

Track work in GitHub Issues, use a short-lived branch for each task, and open a
pull request into `main`. Request review from another team member and record
verification evidence in the pull request. Use squash merging to keep one
clear commit per completed task.
