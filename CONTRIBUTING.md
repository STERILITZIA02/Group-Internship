# Contributing

Edit Wiki pages directly. For documentation-only changes in this repository, you may commit directly to `main` or open a pull request if you want feedback.

For changes that include code, configuration or demo submodule updates, follow these steps:

1. Select an issue from the [project board](https://github.com/users/STERILITZIA02/projects/2). Start a task branch from the target repository’s latest `main`.
2. Open a pull request with the issue link, the result and the checks you ran. Include a screenshot or render when the change is visual.
3. Request a teammate’s review. Resolve conversations, pass `Repository checks` and squash merge after approval.

For a demo change, link the main issue with `Refs STERILITZIA02/Group-Internship#123`. Close it from the main PR that [updates the recorded demo version](demos/README.md#update-a-demo-version).
