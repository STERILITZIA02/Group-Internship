# Sprint workflow

## Pick up work

Use a [main-repository issue](https://github.com/STERILITZIA02/Group-Internship/issues/new/choose) to record the outcome, scope and acceptance check. Assign an owner and a [sprint milestone](https://github.com/STERILITZIA02/Group-Internship/milestones). Label the implementation repository with `area:main`, `area:demo-3d` or `area:demo-platform`.

Move the issue through **Todo → In Progress → In Review → Done** on the [board](https://github.com/users/STERILITZIA02/projects/2). If work is blocked, name the dependency and the next action in the issue.

## Agent handoff

Add `agent-ready` when the issue names the target repository, starting files and how to verify the result. Give the agent the issue link and checkout. On handoff, record the PR or commit, checks run and any work still open.
