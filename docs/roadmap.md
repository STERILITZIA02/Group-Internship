# 10-week roadmap

This is a provisional collaboration framework, not an approved project scope.
Calendar dates and technical deliverables will be set after the brief arrives.

| Week | Focus | Suggested evidence |
| --- | --- | --- |
| 01 | Understand the challenge and form the team | Agreed brief, roles, initial backlog |
| 02 | Explore options and reduce the largest risks | Research, feasibility demo, approach decision |
| 03 | Establish the first end-to-end slice | Runnable baseline and setup instructions |
| 04 | Develop the first core capability | Demo against agreed acceptance criteria |
| 05 | Integrate and review at the midpoint | Midpoint demo, feedback, revised backlog |
| 06 | Extend the core solution | Integrated capability with verification evidence |
| 07 | Address user feedback and remaining gaps | Stakeholder feedback and resulting changes |
| 08 | Stabilize and verify | Test results, defect fixes, risk review |
| 09 | Prepare delivery and handover | Documentation, release candidate, demo rehearsal |
| 10 | Present and hand over | Final demo, deliverables, retrospective |

Use weekly GitHub milestones to group issues once the work is defined. Adjust
this sequence when the challenge requires a different approach. Each weekly
update should link to actual work and explain any scope changes.
